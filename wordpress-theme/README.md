# Hunza 4 Season Tours — WordPress theme

The React/Vite site in this repo, converted to an installable WordPress theme.

- **Theme folder:** `hunza-4-season-tours/`
- **Upload this zip:** `hunza-4-season-tours.zip`

Install: WordPress → Appearance → Themes → Add New → Upload Theme → activate, then Settings → Permalinks → Save Changes.

See `hunza-4-season-tours/README.md` for contact customizer settings, URLs, and how to rebuild CSS.
